# IRA Laser Tools (ROS2)

This library includes some tools for laser handling in ROS2. At the moment two nodes are available:

 - laserscan_multi_merger
 - laserscan_virtualizer

Both use part of the pointcloud_to_laserscan code available in ROS.

## Dependencies

- ROS2 (Humble, Iron, or later)
- PCL (Point Cloud Library)
- tf2_ros
- laser_geometry
- pcl_ros
- pcl_conversions

## Building

```bash
# Navigate to your ROS2 workspace
cd ~/ros2_ws/src
git clone https://github.com/ebrahimabdelghfar/ira_laser_tools.git
cd ..
colcon build --packages-select ira_laser_tools
source install/setup.bash
```

## Nodes

### laserscan_multi_merger

Allows to easily and dynamically merge multiple, same time, single scanning plane, laser scans into a single one. This is very useful for using applications like nav2, slam_toolbox on vehicles with multiple single scanning plane laser scanners, as these applications require just one laser scan as input.

#### Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `destination_frame` | string | `cart_frame` | Target frame for merged scan |
| `cloud_destination_topic` | string | `/merged_cloud` | Topic for merged point cloud output |
| `scan_destination_topic` | string | `/scan_multi` | Topic for merged laser scan output |
| `laserscan_topics` | string | `` | Space-separated list of laser scan topics to merge |
| `angle_min` | double | `-2.36` | Minimum angle of output scan (radians) |
| `angle_max` | double | `2.36` | Maximum angle of output scan (radians) |
| `angle_increment` | double | `0.0058` | Angle increment between scan points |
| `time_increment` | double | `0.0` | Time between measurements |
| `scan_time` | double | `0.0333333` | Time between scans |
| `range_min` | double | `0.45` | Minimum range value |
| `range_max` | double | `25.0` | Maximum range value |

#### Launch

```bash
ros2 launch ira_laser_tools laserscan_multi_merger.launch.py
```

### laserscan_virtualizer

Allows to easily and dynamically generate virtual laser scans from a pointcloud such as the one generated by a multiple scanning plane laser scanner (e.g., a velodyne scanner). The only requirement is the rototranslation between the virtual laser scanner and the base frame to be known to TF.

#### Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `base_frame` | string | `cart_frame` | Base reference frame |
| `cloud_topic` | string | `/cloud_pcd` | Input point cloud topic |
| `output_laser_topic` | string | `` | Output laser scan topic (empty = use frame names) |
| `virtual_laser_scan` | string | `` | Space-separated list of virtual laser frame names |
| `angle_min` | double | `-2.36` | Minimum angle of output scan (radians) |
| `angle_max` | double | `2.36` | Maximum angle of output scan (radians) |
| `angle_increment` | double | `0.0058` | Angle increment between scan points |
| `time_increment` | double | `0.0` | Time between measurements |
| `scan_time` | double | `0.0333333` | Time between scans |
| `range_min` | double | `0.45` | Minimum range value |
| `range_max` | double | `25.0` | Maximum range value |

#### Launch

```bash
ros2 launch ira_laser_tools laserscan_virtualizer.launch.py
```

## Dynamic Parameters

In ROS2, all parameters can be changed at runtime using `ros2 param set`:

```bash
ros2 param set /laserscan_multi_merger angle_min -1.57
ros2 param set /laserscan_multi_merger angle_max 1.57
```

## Migration from ROS1

This package has been migrated from ROS1 to ROS2. Key changes include:
- Replaced `roscpp` with `rclcpp`
- Replaced `tf` with `tf2_ros`
- Replaced `dynamic_reconfigure` with ROS2 parameters
- Launch files converted from XML to Python
- Message types updated to ROS2 format
